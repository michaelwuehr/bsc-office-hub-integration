# BSC - Office Hub Integration

WordPress-Plugin der Bavarian Soap Company: verbindet den WooCommerce-Shop mit dem BSC Office Hub.

Module: Monitoring, Doppelbestellungs-Erkennung, Sale-Banner ([bsc_hub_sale]), Kundendokumente, Preisliste, Woidsiederei-Chat.

Nachfolger von "BSC WC Health Monitor". Quellcode wird aus dem Office-Hub-Repo (wp-plugin/bsc-office-hub-integration/) gespiegelt; Releases hier dienen dem WordPress-Auto-Update (Asset: bsc-office-hub-integration.zip).
